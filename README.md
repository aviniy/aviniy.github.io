# Aviniy's Lab

`https://aviniy.github.io/`는 개인 홈페이지이고, 기술 블로그 Aviniy's Lab은
`https://aviniy.github.io/lab/`에서 제공된다. 예전 게시글·카테고리·검색 주소는 대응하는
`/lab/` 주소로 정적 리디렉션된다.

수식은 Markdown 본문에서 `$$a^{-1}$$`처럼 작성하거나, 아래처럼 `$$`로 감싸 별도 줄에 표시한다.
코드 블록과 인라인 코드 안에서는 수식을 변환하지 않는다.

```text
$$
1 = aa^{-1} \bmod m
$$
```
