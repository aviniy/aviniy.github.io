## 코드

```python
for i in range(3):
    n = int(input())
    a = 0
    for j in range(n):
        a += int(input())
    if a > 0:
        print("+")
    elif a < 0:
        print("-")
    else:
        print("0")
```

이렇게 간단히 문제의 의도대로 코드를 작성할 수 있다.

### 코드 설명

문제에서 총 3개의 테스트 셋이 주어진다고 하였으므로 3번 반복하는 반복문을 작성한다. 각 테스트 셋의 첫 번째 줄에는 정수의 개수 N이 주어지므로 이를 변수 `n`에 저장하고, 합계를 저장하는 변수 `a`를 0으로 초기화한다. 이후 `n`만큼 반복하는 반복문을 작성하여 입력받는 값을 계속 더하고, 조건문을 통해 최종 합계의 부호를 판별한다. (사실 반복문에 쓰이는 변수 i와 j는 쓰지 않아서 언더바 (`_`)로 놔둬도된다.)



### 내 코드의 문제

![image.png](/images/image-87.png)

맞긴 맞았지만.. 시간이 오래 걸리는걸 확인할 수 있었다. 그럼 왜 이렇게 오랜 시간이 소비되었을까?

```python
for j in range(n):
    a += int(input())
```

내 원래 코드에 이런 부분이 있었다. 기본적으로 `input()`함수는 원래 사람이 키보드로 데이터를 입력하는 대화형 환경까지 고려해서 만들어진 함수이다. `input()`함수는 다음과 같은 처리를 수행한다.

```
표준 입출력 스트림 확인, 출력 버퍼 비우기(flush), 입력 스트림에서 한 줄 읽기, 마지막 줄바꿈 문자(\n) 제거, 문자열 반환
```

그리고 내가 작성한 코드에서는 최대 300,003번의 입력이 발생하므로 부가적인 처리 비용이 계속 누적이 된다. 그럼 효율적으로 작동되게 할려면 코드를 어떻게 작성해야할까?



### 효율적인 코드 작성

파이썬의 `sys`모듈을 사용하면 표준 입력 스트림에 직접 접근할 수 있다. `sys.stdin.readline()`은 `input()`과 달리 대화형 입력을 위한 일부 부가적인 처리 과정을 생략하고, 표준 입력 스트림에서 한 줄을 읽어온다.

- `sys`: 파이썬의 시스템 관련 기능을 제공하는 모듈
- `stdin`: 표준 입력(Standard input)
- `readline()`: 입력 스트림에서 한 줄을 읽는 메서드



```python
import sys
input = sys.stdin.readline

for _ in range(3):
    n = int(input())
    a = 0
    for _ in range(n):
        a += int(input())
    if a > 0:
        print("+")
    elif a < 0:
        print("-")
    else:
        print("0")
```

이렇게 `input`에 `sys.stdin.readline`을 할당하면 기존 코드에서 `input()`을 호출할 때 `sys.stdin.readline()`이 대신 실행된다. 이를 통해 불필요한 입력 처리 과정을 줄이고, 대량의 데이터를 좀 더 효율적으로 처리할 수 있다.

또한 기존 반복문에서 변수 `i`와 `j`의 값을 사용하지 않으므로 `_`로 변경하여 코드의 의도를 명확하게 표현하였다.

![image.png](/images/image-88.png)

입력 방식만 변경했음에도 실행 시간이 5142ms에서 166ms로 크게 단축되었음을 확인할 수 있다.
