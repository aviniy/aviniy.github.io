## 코드

```python
N = int(input())
F = int(input())

N = N - (N % 100)

for i in range(0, 100):
    if (N + i) % F == 0:
        print(f"{i:02d}")
        break
```

### 코드 해석

먼저 N과 F를 입력받는다. 그리고 N의 마지막 두 자리를 `00`으로 만들기 위해 N에서 N을 100으로 나눈 나머지를 빼준다.

(예시: `1021 -> 1021 - (1021 % 100) -> 1021 - 21 -> 1000`)

이후 0부터 99까지 반복문을 돌면서 `N + i`를 `F`로 나눈 나머지가 0인지 확인한다.

조건을 만족하면 `i`를 두 자리 형식으로 출력하고 반복문을 종료한다. 0부터 오름차순으로 검사하기 때문에 가장 작은 값을 출력할 수 있다.
