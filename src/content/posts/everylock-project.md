EveryLock은 로그인 실패 횟수와 계정 잠금 정책이 사용자 경험과 보안에 어떤 영향을 주는지 살펴보기 위해 만든 **로컬 실습용 프로젝트**다.

서로 다른 인증 오류 메시지가 계정 존재 여부를 짐작하게 할 수 있는지, 반복 실패 후 잠금 정책이 정상 사용자의 접근성에 어떤 영향을 줄 수 있는지를 연구 주제로 삼았다. 실서비스에서 관찰한 일부 응답 차이는 연구의 출발점이었으며, 서버 내부 구현이나 실제 계정 잠금에 따른 서비스 거부 가능성을 확정한 결과는 아니다.

로컬 POC는 가상 계정 생성, 로그인 실패 횟수 누적, 10회 실패 후 잠금, 잠금 상태 표시와 해제, JSON 로그 내보내기 기능을 갖췄다. GUI와 로컬 웹 인증 서버로 동작하며 외부 호스트에 요청하지 않도록 설계했다.

이 프로젝트는 인증 흐름의 **관찰 결과와 가설을 분리해 기록하는 연습**이자, 계정 잠금 정책의 효과를 통제된 환경에서 재현하는 도구다.
